# 项目验收清单

本清单验收开发起步阶段的目标设计，所有项目保持未勾选；文档可解析不表示业务已经通过。验收覆盖三服务职责、内部调用与外部接口的完整行为。当前单体源码的差异用于迁移排查，不能代替目标验收。

## 1. 拓扑、治理与隔离

- [ ] A01：用户、农资买卖、支付是三个可独立启动、停止和部署的业务应用；网关及 Nacos 为基础设施，不另算业务服务。
- [ ] A02：网关与三服务注册、发现和配置读取正常，环境命名空间隔离；配置变更可回溯，秘密不出现在仓库或日志中。
- [ ] A03：三个数据库账号各自只访问本服务库；无跨库查询、跨服务外键或共享实体 Repository。
- [ ] A04：网关优先将 /orders/{id}/payments 路由给支付服务；其余用户、商品、履约和退款路由按所属服务正确转发，公网不能访问 /internal/** 或伪造身份头。
- [ ] A05：锁定并验证 Java、Spring Boot、Spring Cloud Gateway、Nacos 客户端与服务端的兼容版本；现有 POM 不代表新工程已兼容。

## 2. 用户与经营权限

- [ ] A06：注册不能指定管理员、商家或机主角色；令牌过期、退出吊销和账号无效后受保护请求被拒绝。
- [ ] A07：入驻申请、审批及角色更新同库原子提交；重复待审申请、重复冲突审批和自审批被拒绝；拒绝原因可查询。
- [ ] A08：普通用户、未批准商家或其他商家不能操作商品、订单、退款及回复；私有资源无权读取返回 404。
- [ ] A09：S01 不可用时不通过客户端角色信息绕过认证；内部凭据具有调用方及接口范围，用户令牌不能调用内部接口。

## 3. 农资交易与库存

- [ ] A10：多商家购物车生成独立订单；任一商品失效、库存不足或自购，整个结算回滚，不遗留订单或预留。
- [ ] A11：库存为 1 时并发两次下单仅一单成功；同键重放同一批订单，同键不同内容返回 409；重复商品数量先合并再校验。
- [ ] A12：下单预留、支付消费、关闭释放、退款成功回补及销量变化正确，库存流水唯一；商品改价不影响订单快照。
- [ ] A13：商家只能查询自己的销售订单，不泄露其他拆单的商品或收货信息；价格由服务端计算，金额为两位小数字符串。
- [ ] A14：禁售阻止新购买和商家重新上架，解除禁售不自动上架；已有订单仍能履约或退款。

## 4. 沙箱支付与服务故障

- [ ] A15：未配置供应商明确返回 503，不伪造支付成功；供应商选型后补齐签名、通知、应答、查询、关闭和退款协议。
- [ ] A16：浏览器声称成功、无效签名、错误金额/币种/环境不改变订单；重复及乱序有效通知只产生一次支付副作用。
- [ ] A17：支付创建在途时发起取消，或支付通知竞争超时关闭，库存不会提前释放；一个订单不会出现第二个可支付通道交易。
- [ ] A18：支付服务已成功但农资服务不可用时，通知持久化重投；恢复后或通过 P03 核对收敛，不重复增加销量或消费预留。
- [ ] A19：超期或取消后确认收款，自动系统全额退款，不复活订单，不重复回补库存；未知结果保留明确状态。

## 5. 履约、退款及评价

- [ ] A20：发货与退款申请竞争同一 PAID 状态，只允许一个成功；发货必须填承运方和运单号，不能修改任意订单状态。
- [ ] A21：商家拒绝退款恢复 PAID；同意只是开始执行，未确认资金退回前不恢复库存或允许发货。
- [ ] A22：退款执行与农资结果投影分属两库；命令、事件、进程重启与丢失响应的重放不会退款两次或回补两次。
- [ ] A23：退款 UNKNOWN/FAILED 先查通道，再按原 refundNo 重试；P04 可修复丢失投影，管理员不能直接改资金结果。
- [ ] A24：买家收货后直接完成；仅本人已完成订单项可评价，每项一次，多商品分别评价；商家只能回复本人商品一次。

## 6. 交付与证据

- [ ] A25：Web 目标组件使用 MUI，完成 Ant Design 迁移；成功码、分页、金额、图片数组、错误和评价字段与服务端契约一致，覆盖用户、商家与管理员必要操作。
- [ ] A26：四张 Excalidraw 可编辑导入，图中目标功能、服务编号、调用编号、表归属和接口一致，无越界文字或穿字连线。
- [ ] A27：三个独立库的主键、外键、唯一键、基数及跨服务逻辑引用满足服务隔离与业务唯一性；迁移在独立开发数据库验证。
- [ ] A28：每项记录执行人、提交号、环境、请求响应、前后状态、数据库流水、日志关联号及失败/复测证据，未执行不勾选。

## 后续移动端验收要求

Flutter 移动客户端在后续建设时单独验收，当前不标记为已交付：使用 Material 组件，与 Web 保持主题色、字体层级和核心业务术语一致；验证触控目标、文字缩放、可访问性、网络失败与防重复提交；通过同一网关执行同等身份和资源权限校验。Web 的响应式展示不能替代 Flutter App 验收。

## 不纳入本期

农机共享、真实资金与分账提现、发货后退换货、部分支付与部分退款、拆包物流、自动收货、通知平台及独立搜索/库存/订单服务。任何扩围应先更新业务边界、调用、API、数据库和验收，不自动增加业务服务数量。
